AI Staffing Assistant
AI-powered project for matching job requirements with professional skills.

🎯 Project Goal
The goal of this project is to learn how Data and Artificial Intelligence can be used to analyze job requirements and compare them with professional profiles.

This project is part of my learning journey in Data & AI Engineering.

🚀 Planned Features
Extract skills from job descriptions
Compare job requirements with professional profiles
Identify matching skills
Identify skill gaps
Generate a match score
Use AI to explain the match
